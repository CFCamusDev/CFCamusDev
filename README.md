## 👨🏻‍💻 Sobre mí

Diseño e implemento **soluciones de software de extremo a extremo**, desde interfaces intuitivas y reactivas en web y móvil, hasta arquitecturas backend seguras y escalables.

Mi enfoque combina **buenas prácticas de ingeniería**, **arquitectura limpia**, **diseño de bases de datos relacionales** y **contenerización**, asegurando que cada sistema sea mantenible y soporte el crecimiento del producto.

Trabajo con el ecosistema de **JavaScript/TypeScript**, **PHP**, **Python** y **Java**, construyendo APIs RESTful con **Laravel** y **Node.js/Express**, interfaces modernas con **React** y **Tailwind CSS**, y aplicaciones móviles multiplataforma de alto rendimiento con **Flutter** y **React Native**.

> 💡 _"El buen software no solo resuelve el requerimiento de hoy, sino que facilita evolucionar la solución mañana."_
